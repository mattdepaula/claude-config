# 🤖 claude-config

My personal [Claude Code](https://claude.ai/code) configuration, managed as a dotfile. This repo is symlinked to `~/.claude` via my [dotfiles](https://github.com/mattdepaula/dotfiles).

## Contents

- `settings.json` — Claude Code settings (permissions, env, plugins, UI)
- `CLAUDE.md` — persistent instructions loaded into every Claude session
- `commands/` — custom slash commands
- `scripts/` — helper scripts (e.g., status line)
- `claude-powerline.json` — powerline segment config
- `statusline-command.sh` — status line script for the Claude TUI
